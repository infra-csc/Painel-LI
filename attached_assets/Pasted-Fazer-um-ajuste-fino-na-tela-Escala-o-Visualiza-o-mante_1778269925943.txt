Os dropdowns abertos também devem seguir o mesmo padrão visual.

Padronizar os menus abertos:

- mesma altura de item
- mesmo estilo do campo de busca interno
- mesma cor de item selecionado
- mesma linguagem para checkboxes e listas

2. Melhorar o campo de busca dentro dos dropdowns
Nos dropdowns que possuem busca interna, melhorar o visual para ficar mais refinado e consistente com o restante da tela.

Ajustar:
- campo de busca mais alinhado
- ícone de busca mais bem posicionado

- espaçamento melhor

3. Melhorar o ícone de visualização (olho)
O ícone de olho da tabela hoje está discreto demais.
Como ele só parece ganhar destaque no hover, passa a sensação de que está desabilitado.

Quero corrigir isso.

Ajustes:
- deixar o ícone visível já no estado normal
- manter aparência leve, mas claramente clicável
- melhorar contraste
- aumentar levemente presença visual
- aplicar hover suave sem depender totalmente do hover para parecer ativo
- pode usar fundo bem sutil, borda suave ou botão fantasma discreto
- manter estilo clean e pequeno
- não exagerar para não poluir a tabela

Objetivo:
o usuário deve bater o olho e entender que é uma ação clicável de “visualizar”, e não um item desabilitado.
